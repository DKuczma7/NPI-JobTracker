# JobTracker - Aplikacja do zarządzania rekrutacjami

Projekt realizowany w ramach przedmiotu NPI.

## Zespół projektowy
* Dawid Kuczma
* Iryna Kuptsova
* Zuzanna Szlachcińska

## O projekcie
Aplikacja umożliwiająca zapisywanie ofert pracy, śledzenie etapów rekrutacji, dodawanie notatek i przypisywanie odpowiedniej wersji CV. Rozwiązuje problem rozproszonych informacji w arkuszach kalkulacyjnych i skrzynkach e-mail.

## Najważniejsze funkcje (MVP)
* Dodawanie i edytowanie ofert pracy.
* Zmiana statusu rekrutacji z listy dostępnych opcji (np. Wysłane, Rozmowa, Odrzucono).
* Przypisywanie wersji wysłanego pliku CV do ofert.
* Dodawanie notatek i linków do ogłoszeń.

## Technologie
* Frontend: HTML, CSS, JavaScript
* Baza danych: localStorage (dane zapisywane lokalnie w przeglądarce)

## Jak uruchomić?
Aplikacja nie wymaga serwera. Wystarczy pobrać repozytorium i uruchomić plik `index.html` w dowolnej przeglądarce internetowej.
